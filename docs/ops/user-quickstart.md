# AXON quick-start (invited users)

Welcome to the AXON private beta. Here's the fastest path through the product.

1. **Sign in with GitHub.** AXON only reads your identity — no repository
   access is requested.
2. **Redeem your invitation.** Enter the code you were sent. Signing in alone
   doesn't grant access.
3. **Create or import an architecture.** Start blank, start from the sample
   system, generate one from a prompt, or import a `docker-compose.yml`.
4. **Review every generated or inferred component.** *Generated architecture
   requires review* — check names, categories, and connections.
5. **Run an audit** and open a finding's evidence. *Audit findings evaluate the
   architecture you represented*, not a live system.
6. **Preview a recommendation** and review **Current / Recommended / Diff**.
   *Recommendations modify the AXON document only* — they never touch deployed
   infrastructure. Apply only when appropriate, then **rerun the audit** to
   confirm the finding resolves.
7. **Review the simulation assumptions**, then run a scenario. *Simulations are
   estimates, not production benchmarks.*
8. **Submit feedback** any time — it's never attached to a project and never
   includes your architecture content.

Other things you can do: export a project or all your account data as JSON from
**Account**, and delete your account there (this removes your AXON model only,
not any deployed infrastructure).

A note on Compose import: *it reflects the supplied configuration, not a running
environment.* Do not paste secrets or upload `.env` files.

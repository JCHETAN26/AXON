# AXON Competitor Parity Scorecard

This scorecard tracks the full-scope goal of exceeding diagram-focused products by combining visual quality with grounded architecture intelligence.

Scores use 0-5:

- 0: Not started
- 1: Foundation only
- 2: Partial usable slice
- 3: Solid local/product slice
- 4: Competitive feature
- 5: Differentiated, validated, production-ready capability

## Current Competitive Read

AXON is stronger than a pure mockup because the core architecture model, validation, security boundaries, deterministic engines, and tests are real. It is not yet competitor-complete because most premium visual workflows and live evidence loops are still partial.
